Microsoft Visual C++ Runtime
============================

The Windows executable of QuestionSheet2LMS contains the following
Microsoft Visual C++ Runtime components:

    VCRUNTIME140.dll
    VCRUNTIME140_1.dll

These files originate from the official Python 3.14.7 Windows
distribution used to build QuestionSheet2LMS and are incorporated
into the executable by PyInstaller.

applicable Microsoft Software License Terms and redistribution
conditions.
